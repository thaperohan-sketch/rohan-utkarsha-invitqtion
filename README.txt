ROHAN & UTKARSHA — LOTUS REVEAL INVITATION

Open index.html in a browser to preview. Upload index.html and the entire assets/ folder to the root of the GitHub Pages repository.

The opening screen uses the exact Ganpati image supplied by the user (no crop or alteration). A tap on "Open Our Invitation" starts the bundled Sukh Kalale MP3 and transitions into the invitation. Mobile browsers require this tap to permit audio playback.

Included: lotus-inspired golden ornament styling, falling petals, scratch-to-reveal date/time, venue and Google Maps link, countdown, and #Engineeredfordoctor.

If Sukh-Kalale.mp3 is not present in assets/, add the original MP3 there using that exact filename.
